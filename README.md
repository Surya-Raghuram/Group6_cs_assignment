## 1. Project Overview

This project demonstrates the exploitation and mitigation of web server vulnerabilities as part of the Cyber Security assignment.

Each group member implements one vulnerability variant, demonstrates its exploitation, identifies the root cause, and implements a mitigation to prevent the attack.

The four vulnerability categories covered in the assignment are:

1. SQL Injection (SQLi)
2. OS Command Injection
3. Cross-Site Scripting (XSS)
4. Cross-Site Request Forgery (CSRF)
